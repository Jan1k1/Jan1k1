## What I'm building

- **Sniffer Studio**: tools for Minecraft server security and moderation.
  - [voicesniffer-processor](https://github.com/Jan1k1/voicesniffer-processor): self-hostable speech moderation. Opus in, verdict out.
- **MCAnalytics**: analytics for Minecraft networks.
  - [mcanalytics-loader](https://github.com/Jan1k1/mcanalytics-loader): drop it on Velocity or Paper, run `/mca pair`, done.
- **Peakstone**: licensing for paid Minecraft plugins.
  - [peakstone-sdk](https://github.com/Jan1k1/peakstone-sdk): licence check SDK for Paper, Velocity and Bukkit.
